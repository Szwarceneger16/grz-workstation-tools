# yubico-auth switch

Przełącza aktywną wersję na jedną z już zainstalowanych.

## Użycie

```bash
yubico-auth switch <WERSJA>
yubico-auth switch --version WERSJA
yubico-auth switch --list
yubico-auth switch [--dry-run]
yubico-auth switch --help
```

## Opcje

- `<WERSJA>` — wersja do aktywacji
- `--version WERSJA` — alternatywny zapis podania wersji
- `--list` — pokaż zainstalowane wersje
- `--dry-run` — pokaż plan bez zmian na dysku
