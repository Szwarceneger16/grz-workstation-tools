# yubico-auth status

Pokazuje zbiorczy status instalacji.

## Użycie

```bash
yubico-auth status
yubico-auth status --help
```

## Co pokazuje

- aktywną wersję
- target symlinku `current`
- plik `.desktop`
- keyring do weryfikacji
- listę zainstalowanych wersji
- status timera `yubico-auth-check.timer`
- najnowszy release i informację, czy update jest dostępny
